Menol – Clothing Website

Menol is a modern and responsive clothing website designed to showcase fashionable apparel with a clean and user-friendly interface. 
The website is built using HTML, CSS, and JavaScript, focusing on smooth design, responsiveness, and basic interactivity.
Features
Stylish and minimal UI design
Fully responsive layout for all devices
Interactive elements using JavaScript
Clean and structured code
Easy to customize and extend

 Technologies Used
HTML5 – Structure of the website
CSS3 – Styling and layout
JavaScript – Interactivity and dynamic behavior
